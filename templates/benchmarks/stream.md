# Kinesis or Kafka stream benchmark

| Area | Measures |
| --- | --- |
| Demand | records or bytes per second, key distribution, producer count |
| Response | publish and end-to-end latency, error, retry |
| Consumer | lag, fan-out, consumer count, rebalance or shard behavior |
| Retention | replay window, storage growth, schema compatibility |
| Reliability | duplicate, ordering, poison message, dead-letter recovery |
| Cost | shard or broker, storage, transfer, consumer and operations time |
