# DynamoDB benchmark

| Area | Measures |
| --- | --- |
| Demand | access pattern, item size, partition key distribution, read/write mix |
| Response | latency, errors, timeout |
| Capacity | consumed capacity, throttle, retry, adaptive capacity |
| Distribution | hot partitions, skew, global secondary index impact |
| Recovery | point-in-time recovery or export restore evidence |
| Cost | capacity mode, storage, index, stream, backup, request unit cost |
