# RDS benchmark

| Area | Measures |
| --- | --- |
| Demand | transaction and query mix, rows, payload, connection count |
| Response | query and transaction latency, errors, timeout |
| Contention | active connections, pool wait, lock wait, deadlock |
| Storage | IOPS, throughput, queue, cache hit, growth |
| Recovery | replica lag, backup, restore time, observed RPO/RTO |
| Cost | instance, storage, I/O, backup, transfer, DBA and recovery time |
