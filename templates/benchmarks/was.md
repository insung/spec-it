# WAS or backend service benchmark

| Area | Measures |
| --- | --- |
| Demand | request rate, concurrency, payload mix |
| Response | p50/p95/p99 latency, throughput, errors, timeout |
| Saturation | CPU, memory, connection pool, thread or event loop, queue depth |
| Network | connection setup, bandwidth, retransmission when relevant |
| Cost | instance or container time, transfer, request unit cost |
| Operations | setup, scaling, diagnosis, recovery time |
