# OpenSearch benchmark

| Area | Measures |
| --- | --- |
| Demand | ingest rate, query mix, document and index size |
| Response | index and query latency, errors, rejection |
| Capacity | CPU, heap, GC, disk, watermarks, thread pool queue |
| Layout | shard count and size, replica, segment and merge behavior |
| Recovery | snapshot, restore, relocation and rebalance time |
| Cost | host or managed node, storage, transfer, snapshot, operations time |
