# Human-in-the-loop

Human-in-the-loop는 모든 단계에서 승인받는 방식이 아니라, 사람이 소유한 판단이 필요한 경계에서만 멈추는 방식입니다.

필수 개입 범주는 관측 가능한 동작 또는 수용 기준의 모호성, 공개 계약 변경, 보안·권한 영향, 데이터 손실·보존·마이그레이션, 비용·인프라 경계 변경입니다. 테스트·문서·코드 충돌은 먼저 권한 순서와 증거로 해소하고, 그 결과도 사용자 의도를 확정하지 못할 때 멈춥니다.

정지 시 AI는 선택지, 추천, 영향, 위험, 예상 diff, 롤백, 증거를 한 묶음으로 제시합니다. 같은 실패에 대해 서로 다른 가설 두 개를 검증한 뒤에도 해결되지 않으면 사람이 판단합니다.
