## 검증

| 사례 | AC | 명령·작업 디렉토리 | 기대 결과 | 결과 |
| --- | --- | --- | --- | --- |
| <a id="tc-03"></a>TC-03 | AC-05, AC-06 | Markdown 상대 링크·후보 front matter 검사 및 git diff --check, 리포 루트 | 링크·구조 유효, 정적 검사를 행동 통과로 보고하지 않는 기록 | 미실행 |
| <a id="tc-04"></a>TC-04 | AC-01, AC-02, AC-04, AC-05 | 새 실행자에게 같은 일반 RDS/EC2 질문·기존 승인 범위 내 구성 검토·S3 재사용 요청을 제공. 기준선: 기존 AGENTS/converge, 후보: 변경된 안내와 선택적 pair 지침. 각 입력·조건 3회 | 일반 질문 직접 답변, 확인 없는 완료·외부 수정·분리 의무 단정 없음. 질문 수와 발견·추천 차이를 기록. 필요성·자동 선택 효과는 미확인 | 미실행 |
| <a id="tc-05"></a>TC-05 | AC-07, AC-08 | git diff --name-only 기준선..HEAD, 원본 11개 후보 SHA-256·기존 index 대조, 계획·분리 상태 검사 | 보호 경로와 원본 보존, 이번 변경만 전달 | 미실행 |

TC-04의 구체 요청문과 대상 지침은 구현 세션이 handoff에 기록한다. 새 실행자에게 기대 결과나 다른 실행 결과를 주지 않는다. 기준선과 후보의 명시적 지침 제공은 합성 실험이며 호스트의 implicit 선택 테스트가 아니다. 기준선에 pair가 없다는 사실을 테스트 실패로 만들지 않는다.
