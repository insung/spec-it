## 전달과 롤백

| 항목 | 내용 |
| --- | --- |
| 전달 방법 | 문서 커밋·push 후 main 대상 PR 생성. 서비스 배포 없음 |
| 필요 승인 | 구현·검증·커밋·push·PR은 사용자 요청 범위. 머지는 별도 사용자 승인 |
| 적용 후 확인 | 원격 PR HEAD·Issue 연결·문서 링크·담당자·라벨 확인 |
| 롤백 | 머지 전 PR 수정 또는 닫기. 머지 후 문서 커밋 revert를 별도 승인 범위로 진행 |
