# 0.3.0 release checklist

이 문서는 정책 저장소 자체의 0.3.0 구조와 릴리스 경계를 검증하는 증분 증거입니다. 개별 프로젝트의 준수나 실행 가능한 migration·monitoring system의 구현 증거가 아닙니다.

## Release identity

- Version: `0.3.0`
- Date: `2026-09-08`
- Previous version: `0.2.0`
- Release tag: not-created
- Compatibility: new obligations require explicit project reconvergence; no automatic upgrade

`schema_version: 0.1.0`은 정책 버전이 아닙니다. 기존 artifact 형식을 깨지 않았으므로 이번 릴리스에서도 올리지 않습니다.

## Verification

- [x] `DATA-009`, `OBS-003` front matter가 schema를 만족하고 기존 규칙과 의미가 중복되지 않는다.
- [x] `capability/db-migration`, `capability/data-pipeline`이 profile schema를 만족하고 존재하는 rule ID만 참조한다.
- [x] DB 실행 도구·저장소 topology·UI와 project threshold를 공통 의무로 고정하지 않는다.
- [x] application startup의 DDL 실행과 읽기 전용 compatibility guard를 구분한다.
- [x] scheduled pipeline 완료 증거가 step marker가 아니라 terminal data outcome을 포함한다.
- [x] Markdown 링크, version, manifest·lock digest, template와 migration guide가 일치한다.
- [x] 신규 enforcement가 `planned`이고 Phase 0 결과가 `human-review`임을 명시한다.
- [x] 공개 core에 MI schema, account, repository 또는 incident 식별 정보가 없다.

## Known limits

- release manifest schema, bundle assembler, migration runner, DB connector, drift detector와 UI는 구현하지 않았습니다.
- runtime data checks, alert delivery와 replay executor도 구현하지 않았습니다.
- 제품·edition·license 선택과 project별 profile reconvergence는 별도 승인 대상입니다.
