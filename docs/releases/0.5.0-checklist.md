# 0.5.0 release checklist

이 문서는 정책 저장소 자체의 `0.5.0` 릴리스와 공개 경계를 검증하는 증분 증거입니다. 개별 프로젝트 준수, 실제 제품 QA, 일반적인 AI 성공률 또는 실행 validator 구현의 증거는 아닙니다.

## Release identity

- Version: `0.5.0`
- Released on: `2026-09-16`
- Previous published version: `0.4.0`
- Release tag: annotated `v0.5.0`
- Current public authority: annotated `v0.5.0`
- Compatibility: instruction과 선택 artifact가 늘어나는 pre-1.0 minor; 기존 프로젝트는 자동 업그레이드하지 않음
- Policy digest: `sha256:a88fceb1272d3ddb47ebd08e35bacba70872f4dd5f67766eef5958fb69f316a5`
- Self manifest digest: `sha256:2e670edf60788953e98326cfef5407045deb054f047891b991b3b3fb9904c341`

정책 digest는 repository-relative POSIX path 전체를 한 번 정렬한 `VERSION`, `rules/`, `profiles/`, `schemas/`의 path + NUL + bytes + NUL로 계산합니다. skill·template·docs bytes는 이 digest에 포함되지 않으므로, 실행 대상을 재현할 때는 release tag 또는 전체 source snapshot도 함께 고정해야 합니다.

- [x] 검증된 release commit에 annotated `v0.5.0` tag를 만든다.

로컬 검사나 tag 생성만으로 공개를 주장하지 않고 원격 commit·tag identity까지 대조합니다.

## Known limits

- Phase 0의 절차는 instruction-only입니다. 자동 validator/CLI, CI 차단, watcher, connector, QA runner와 통합 UI를 구현하지 않았습니다.
- 24/24는 고정 합성 사례의 한 후보 평가입니다. 실제 애플리케이션의 경로·DB·업데이트·회귀 QA나 고객 문제 해결을 증명하지 않습니다.
- 원문 전체의 의미상 무누락은 계속 human review 대상입니다. 접근할 수 없는 외부 출처는 `unknown`으로 남겨야 합니다.
- 기존 도구에 QA 기록을 둘 수 있고 별도 저장소도 참조할 수 있지만, 도구 간 실시간 동기화와 중앙 서비스는 제공하지 않습니다.
- 정책 digest는 규범 source만 식별합니다. skill·template·docs의 재현성에는 tag 또는 전체 source snapshot이 필요합니다.
- 기존 설치 다섯 스킬은 이 worktree를 가리키는 live symlink여서 미발행 변경을 볼 수 있습니다. 새 `spec-it-impact`는 전역 설치하지 않았습니다.
