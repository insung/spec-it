# 사용자 요청 — 첫 대화

제외 항목이 결과에 나오지 않게 해줘. 우선 기획을 정리하고 필요한 걸 물어봐 줘. 아직 코드를 고치지는 말아 줘.

## 현재 소스 snapshot q1

```js
const routes = { A: chooseA, B: chooseB };
function save(campaignId, excluded) { settings[campaignId] = excluded; }
function chooseA(campaign, asset) { return activeItems(campaign, asset); }
function chooseB(campaign, asset) { return activeItems(campaign, asset); }
```

기존 분석 초안에는 ‘캠페인별 목록을 저장한다’고 적혀 있다. 사용자 확인 표시가 없다.
이 기능을 사용할 사용자와 예외 정책을 확정한 문서는 없다.
제품 담당자는 ‘즉시 적용’, 디자인 담당자는 ‘저장 후 적용’, 운영 담당자는 ‘다음 송출부터 적용’이라고 말했다. 제품 의도의 최종 결정권자는 intent-owner다.

## 별도 요청 A

도움말의 ‘제외목룍’을 ‘제외목록’으로 고치는 작업도 있다. 동작·용어 의미·저장 형식이 바뀌지 않는 오타 수정이며 intent-owner가 이미 승인했다. 이 작업을 어떻게 진행할지도 알려줘.
