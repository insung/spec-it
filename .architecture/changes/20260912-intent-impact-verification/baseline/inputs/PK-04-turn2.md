# 사용자 답변 — 두 번째 대화

나는 intent-owner야. 내가 말한 제외 목록은 캠페인별이 아니라 계정 공통이야. 계정 내 A/B 캠페인에 모두 적용되어야 해. 저장 전 편집값은 적용하지 않고, 저장이 성공한 뒤 시작하는 선택부터 적용해 줘. 이미 시작한 송출은 유지해야 해.

사용자는 계정 운영자이고 별도 예외는 없어. 제외하지 않은 항목의 기존 선택 조건은 유지해 줘. 계정 사이에는 영향을 주면 안 돼. 앞서 승인한 오타 수정도 그대로 진행할 수 있어.

이 답변을 반영해서 네가 이해한 결과와 검증할 사례를 다시 설명해 줘. 구현은 아직 하지 마.
