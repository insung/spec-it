# REL-002 — Availability before hosting

AI는 사람이 선택한 기술을 그대로 기록하기 전에 선택 이유가 기술적 사실과 맞는지 검토합니다. 사람은 최종 선택권을 가지지만 승인된 hard constraint나 SLO를 만족하지 못한 상태로 수렴할 수는 없습니다.
