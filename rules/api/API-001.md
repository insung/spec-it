# API-001 — HTTP path grammar

0.2.0에 도입되었습니다. 첫 고정 segment는 내부 도메인 클래스 이름이 아니라 외부 계약의 resource collection입니다. singleton은 `settings`, 집계는 `summary`, 장기 작업은 job resource처럼 명시적으로 분류합니다. 날짜 기반 API는 소비자가 시점별 계약을 고정해야 하는 별도 제품 선택일 때만 승인합니다.

기존 공개 경로는 스타일 통일만을 위해 깨지 않습니다. 자동 검증은 미구현이며 Phase 0 판정은 `human-review`입니다.
