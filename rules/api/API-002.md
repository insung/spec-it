# API-002 — HTTP mutations and commands

0.2.0에 도입되었습니다. 승인은 `POST /v1/companies/{company_id}/join-requests/{join_request_id}/approve`처럼 command를 드러냅니다. command는 권한·상태 전이·후속 작업을 검증하고 같은 멱등성 키의 재시도가 중복 전이나 중복 알림을 만들지 않게 합니다.

PUT의 전체는 DB entity 전체가 아니라 API가 교체 대상으로 공개한 writable representation 전체입니다. PATCH media type을 정하고, 누락과 `null`, 배열 교체, 충돌 처리의 의미를 계약에 둡니다. 자동 검증과 실행 테스트는 미구현입니다.
