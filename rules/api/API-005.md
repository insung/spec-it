# API-005 — Audience and lifecycle

미발행 0.2.0 초안입니다. audience는 public, partner, internal처럼 분류하고 network exposure와 별도로 기록합니다. 브라우저에서 쓰는 internal API도 인터넷에서 도달 가능할 수 있습니다. 외부와 내부 adapter는 가능한 한 같은 application use case를 호출하되 공개 필드와 권한은 각각 검증합니다.

공통 LTS 기간은 없습니다. 장기 지원을 선택한 프로젝트는 시작점, 기간, 포함되는 수정, 지원 종료 통지 기간, 유지 비용과 책임자를 승인합니다. HTTP에서는 문서·변경 이력과 함께 `Deprecation`과 `Sunset` 신호를 사용할 수 있습니다. 자동 검증은 미구현입니다.
