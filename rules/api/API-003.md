# API-003 — HTTP JSON naming

0.2.0에 도입되었습니다. 경로의 고정 segment는 lower-kebab-case이고 경로 변수, query parameter, JSON field는 lower-snake-case입니다. 이는 HTTP JSON wire contract 규칙이지 모든 언어의 내부 변수명 규칙이 아닙니다.

protobuf payload는 protobuf의 계약 규칙을 따르고, WebSocket은 framing이므로 그 안에서 선택한 JSON 또는 protobuf 규칙을 따릅니다. 실행 validator는 미구현입니다.
