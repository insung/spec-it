# TST-006 — Integration environment safety

0.2.0에 도입되었습니다. 로컬·CI는 실제 엔진의 격리 instance와 결정적 synthetic fixture를 기본으로 하고, stage는 배포 산출물과 중요한 cloud 경계를 검증하며, production은 승인된 bounded smoke와 synthetic actor만 기본 허용합니다.

운영 자료가 필요한 재현은 필요성 승인 뒤 격리 복원, egress·scheduler·notification·payment sink 차단, 최소화 또는 비식별화, 안전 gate, 테스트, TTL 삭제 순서로 다룹니다. synthetic data와 축소 stage가 관찰하지 못하는 분포는 별도 부하·용량 증거로 남깁니다. 실행 자동화는 미구현입니다.
